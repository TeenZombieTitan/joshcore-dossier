Blackbox // Moderation System

Blackbox keeps the record.

Moderation & Community Intelligence

It's a bot that sits in a Discord server and quietly writes down what happens — who turned up, who said what, who won. Every server it runs in gets its own private dossier, readable only by a link that server holds. None of them can see any of the others.

The bot

It runs the server

Ranks, weekly crowns, supply drops, rumours the server votes on, and titles awarded silently the moment you trip the condition. It talks in voice chat, mostly to insult people.

The record

One server, one file

Scores, titles and history are kept per server and never pooled. Being somebody in one community counts for nothing in the next, and you can take your page down whenever you want.

The games

Settle it here

Supply Drop and Breach Point — 1v1, in the browser, no account. Open a room, post the code in Discord, whoever grabs it first is in.

Reading a server's file

Each server's dossier sits at its own address, handed out inside that server with ~site. There is no way to browse from one to another, and no list of them anywhere — if you have not been given a link, there is nothing here to find.

Staff can reissue their server's link with ~dossier rotate, which takes the old address out of service at the next rebuild.
